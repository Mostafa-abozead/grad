# Market Providers — CV-Based Industrial Safety Companies

The market for computer-vision-based workplace safety ("Site Intelligence" / EHS AI) is growing fast. These providers share a common model: they plug into **existing CCTV infrastructure**, run vision AI to detect unsafe acts and conditions in real time (PPE compliance, vehicle–pedestrian proximity, restricted-zone intrusion, ergonomics, fire/smoke, housekeeping), and deliver instant alerts, dashboards, and analytics for EHS teams. Below are the **five international benchmarks** plus the **five Egyptian-market providers** benchmarked for this project — see [`../egypt_market.md`](../egypt_market.md) for the market-level comparison and adopters, and the dedicated file per local provider.
