# 4. Proposed Solution

## 4.1 Description of the Solution

The proposed solution is a software and AI layer that turns existing camera feeds into a reliable, real-time safety event stream, inside one shared and configurable platform. Camera video is processed by detection models, each detection becomes a structured, timestamped event, and the events feed alerts, a central dashboard, a facility risk view, audit reports and an agentic AI assistant. Zones, schedules and rule types come from configuration, any subset of safety services can be adopted, and high-consequence decisions stay with human operators. The project asks: can existing camera feeds be turned, purely in software and AI, into a reliable real-time safety event stream covering detection, risk awareness and reporting?

The current scope is limited to the four core violation types — missing PPE, hazardous-zone intrusion, unprotected work at height, and unsafe machine proximity — plus the platform capabilities above; the broader service catalog is roadmap.
