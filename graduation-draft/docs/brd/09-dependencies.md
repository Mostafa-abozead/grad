# 9. Dependencies

## 9.1 List of Dependencies

The project depends on the following:

| **ID** | **Dependency** |
|---|---|
| D-01 | Access to camera streams or recorded footage from a facility or mockup. |
| D-02 | Compute and storage for model inference, events and evidence; the deployment model (on-premises, cloud, or edge) is to be confirmed (OD-01). |
| D-03 | Supervisor approval of scope and of the accuracy targets and baseline test set in [section 4.4](./04-04-non-functional-requirements.md) (OD-02). |
