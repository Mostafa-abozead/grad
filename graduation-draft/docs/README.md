# Documentation

This folder holds all project documentation for the **AI-Powered Industrial Safety & Surveillance System** — an AI-first, camera-only safety platform for small and mid-sized factories in Egypt/MENA. Start with the [root README](../README.md) for the full pitch.

## Folders

| Folder | Contents |
|---|---|
| [project_overview/](./project_overview/README.md) | Positioning — one-liner, what we offer & differentiators, executive summary, scope/MVP/future scope, users & roles, problem context. |
| [brd/](./brd/README.md) | Business Requirements Document — objectives, requirements, stakeholders, risks, dependencies, traceability (Appendix A) and market evidence (Appendix B). |
| [market/](./market/README.md) | Market research — provider benchmark (10 companies), Egypt market & adopters, job-listing demand evidence, impact & ROI research. |
| [incidents/](./incidents/README.md) | Incident & work-injury evidence — cost of the problem (impact.md), CAPMAS 2024 analysis, source bulletin, incident sheet. |
| [GP_Midterm/](./GP_Midterm/) | Mid-semester evaluation — presentation template, talking points per slide, official docs (pptx/docx). |

## Conventions

- Each folder has its own `README.md` as the entry point.
- Documents carry frontmatter (`title`, `status`, `last_updated`, `tags`) where applicable.
- Evidence claims link back to their sources; vendor-reported figures are labeled as reported, not verified.
