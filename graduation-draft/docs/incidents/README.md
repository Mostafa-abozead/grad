# Incidents — Evidence Base

## Purpose

This folder holds the incident and work-injury evidence used to frame the problem: official Egyptian work-injury statistics, the raw source bulletin, and the structured incident sheet. It grounds the BRD's problem statement and sector prioritization in official numbers, and supports the market analysis in [`../market/`](../market/README.md).

## Key figures (from the 2024 bulletin)

- **8,091 work injuries** across **2,225,169 covered workers** — injury rate **363.6 per 100,000 workers**.
- **Manufacturing** accounts for **45.6%** of all cases (3,687) — the project's primary target sector.
- **Construction**: only 6.9% of cases but **45.8% of deaths** — the clearest severity segment.
- **Falls (32.1%) + collisions with objects (27.6%)** ≈ **60%** of all cases — event types directly addressable by camera-based detection.
- **207,688 absence days**, averaging **25.7 days per case**.

## Limitations

- The bulletin is a **formal-sector snapshot** (7,596 covered establishments) — not a complete count of workplace injuries; the informal sector is excluded.
- Figures support **problem framing and sector prioritization**, not demand or willingness-to-pay claims.
